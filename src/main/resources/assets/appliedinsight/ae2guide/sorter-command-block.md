# 命令执行块（Sorter Command Block）

命令执行块是模组的主要操作终端。把它放在 ME 网络旁边并确保分配到频道，右键打开 GUI 即可分析网络、合并碎片物品，或在服主完成路由配置后执行规则整理。

## 界面布局

GUI 分为三栏：

| 区域 | 内容 |
| :--- | :--- |
| **操作面板**（左） | 三个操作按钮与网络状态灯 |
| **存储概览**（中） | 节点数量、字节用量、内外部存储分布 |
| **分析细节 / 提示**（右） | 健康标志、碎片化提示、最大存储与诊断条目 |

标题栏旁有**帮助按钮**，可打开本页 GuideME 文档。

首次打开时，右侧分析区可能为空。按提示先点击 **分析当前网络** 获取最新数据。

## 网络状态灯

| 状态 | 含义 |
| :--- | :--- |
| ME Online | 方块已接入网络且频道正常 |
| ME Limited | 已接入网络但频道不足 |
| ME Offline | 未接入 ME 网络 |

频道不足时，操作按钮可能无法正常工作。

## 操作按钮

| 按钮 | 功能 |
| :--- | :--- |
| **分析当前网络** | 扫描当前 ME 网络，刷新 GUI 中的存储概览与诊断面板，并在 `dumps/appliedinsight/` 写入分析 JSON |
| **碎片物品合并** | 将散落在多个存储元件中的同种物品归并到一起，降低物品种类占用；完成后在聊天栏显示摘要，详细报告写入 dump 目录 |
| **以绑定配置整理** | 按服主预先配置的路由方案生成搬运计划并立即执行。**需要**先在 `config/appliedinsight/profiles/` 放置路由配置，并用 `/sorter me bindProfile` 绑定到当前网络。详见[路由配置（服主）](routing-profiles.md) |

若未绑定路由配置就点击「以绑定配置整理」，聊天栏会提示「当前 ME 网络未绑定任何全局配置」。

## 分析面板读什么

分析完成后，右侧面板可能显示：

- **健康标志** — 例如碎片化偏高、仅靠外部存储、内外混布、空存储位置等
- **疑似语义节点** — 启发式识别的特殊存储
- **最大存储 / 最碎片物品** — 辅助判断该先合并还是先扩容

数字资产库（DAV）在分析中会单独标注：其容量与碎片化指标不在传统 Drive 单元格统计中，请在 DAV GUI 查看。
