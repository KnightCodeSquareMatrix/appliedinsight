# 快速上手

## 第一步：制作并接入命令执行块

制作一个[命令执行块](sorter-command-block.md)，放在 ME 网络旁并确保分配到频道。右键打开 GUI，确认状态灯为 **ME Online**。

## 第二步：分析当前网络

点击 **分析当前网络**。阅读中间栏的存储概览与右侧的健康标志、碎片化提示。

若提示「请先点击分析当前网络」，说明尚未有缓存数据——执行一次分析即可。

## 第三步：碎片物品合并

若分析显示碎片化偏高，点击 **碎片物品合并**。这会把散落在多个存储元件里的同种物品归并到一起，**减少物品种类占用**——对数字资产库尤其重要，因为 DAV 的物品种类上限是硬约束。

操作摘要在聊天栏显示；详细 JSON 报告在 `dumps/appliedinsight/`。

## 第四步（推荐）：接入数字资产库

1. 制作[数字资产库](digital-asset-vault.md)并接入 ME 网络。
2. 放入空的 AE2 Storage Cell，吸收为容量。
3. 按需开启「导入现有库存」「自动接收后续物品」「自动扩容」。

DAV 会成为网络的主存储池；配合第三步的合并，可长期维持充足的种类空间。

## 第五步（可选）：智能总线

若需要在线缆上对接箱子、机器或漏斗做**有条件的**自动拉取/推送，请参阅[智能总线](smart-bus.md)。

## 服主：规则搬运（可选）

若希望按自定义分区自动搬运物品（命令执行块上的 **以绑定配置整理**），服主需先配置路由 JSON 并绑定网络。玩家主流程不依赖此功能。详见[路由配置（服主）](routing-profiles.md)。

## 查看日志

详细日志与 JSON 报告位于游戏目录下的 `dumps/appliedinsight/`。
