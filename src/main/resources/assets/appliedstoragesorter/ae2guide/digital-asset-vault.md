# 数字资产库（Digital Asset Vault）

数字资产库（DAV）是一个专门用来存放管理卡和区域存储元件的容器。它的外观和操作方式跟 ME 驱动器类似，但有几个重要区别。

## 布局

- **上面 5 格**：存放存储元件（用于规则搬运的目标区域）。
- **中间**：玩家背包。
- **下面 1 格**：插管理卡（只能插镀印区域管理卡）。

## 管理卡机制

管理卡是一张可以记录区域配置信息的卡片。用法：

1. 先在[命令执行块](sorter-command-block.md)里生成计划。
2. 拿着空白管理卡右键命令执行块，卡片会自动镀印上当前的区域配置。
3. 把镀印好的管理卡插入数字资产库，资产库就自动绑定了对应的区域方案。

有了管理卡，你把资产库敲掉再放回去，也不用重新配置。只要卡片还在，配置就不会丢。

## 存储元件状态灯

存储元件上的 LED 灯表示当前状态：

| 颜色 | 状态 |
| :--- | :--- |
| 绿色 | 空 |
| 蓝色 | 有内容 |
| 橙色 | 类型已满，无法存入新品种 |
| 红色 | 容量已满，无法存入更多物品 |
| 黑色 | 没有供能或没有频道 |

## 优先级

点击 GUI 右上角的扳手图标可以调整存储元件的优先级。物品进入网络时会优先存入优先级最高的存储元件。
