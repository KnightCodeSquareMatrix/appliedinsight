# 命令执行块（Sorter Command Block）

命令执行块是这个模组的主要交互方块。把它放在 ME 网络旁边，右键打开就能看到 5 个按钮。

## 按钮说明

| 按钮 | 功能 |
| :--- | :--- |
| **扫描网络** | 扫描整个 ME 网络，输出一份完整的网络清单，包括所有存储元件和物品。结果保存在 `dumps/appliedstoragesorter/` 目录下。 |
| **存储分析** | 在扫描的基础上做深度分析，生成一份存储健康报告，标明哪些存储元件已经快满了、哪些出现了碎片。 |
| **生成计划** | 根据当前存储区域的划分方案，计算出一份搬运计划——哪些东西该搬到哪。 |
| **规划并搬运** | 先生成计划，再执行搬运。这是最常用的按钮。 |
| **整理合并** | 把同种物品合并到一起，不涉及区域划分。 |

## 优先级

命令执行块本身没有优先级设置。存储元件的优先级在 ME 驱动器或数字资产库的 GUI 里调整（点击右上角的扳手图标）。
