# 什么是 Applied Storage Sorter？

Applied Storage Sorter 是一个 Applied Energistics 2 的附属模组，用来管理你的 ME 网络的存储空间。它可以扫描整个网络、分析物品分布，然后根据你定义的规则自动整理物品。

核心功能有两个：

- **合并整理（Merge）** — 把散落在多个存储元件里的同种物品合并到一起，减少存储元件碎片化，腾出更多可用槽位。
- **规则搬运（Rule-based routing）** — 根据筛选条件把物品搬运到指定的区域，例如把建筑材料、贵重装备、杂项物品分别存放。

这两个操作都可以通过一个方块来触发：[命令执行块](sorter-command-block.md)。不需要敲命令。
