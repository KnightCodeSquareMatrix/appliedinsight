# 数字资产库（Digital Asset Vault）

数字资产库（DAV）是一个接入 ME 网络的**集中存储池**。它不像 ME 驱动器那样一格一格地放存储元件，而是把**空的 AE2 Storage Cell 吸收掉**，把 Cell 的字节容量和物品种类上限转化为 DAV 自身的存储空间。

放置并接入网络后即可存取物品；DAV 自带相当于**两张空 1k 物品存储元件**的初始容量，继续吸收 Cell 可进一步扩容。你可以把它当作「把很多个 Cell 合成一个大仓库」的方块来用。

## 内置初始容量

每个 DAV 自带固定基础容量，无需先吸收 Cell 即可开始使用：

| 资源 | 内置值 | 说明 |
| :--- | :--- | :--- |
| **字节** | 2048 | 相当于 2 × 1k Cell（2 × 1024 字节） |
| **物品种类** | 126 | 相当于 2 × 63 types |

这部分容量**不计入**界面上的「已吸收 Cell」计数，但会始终计入总字节/种类上限。NBT 只持久化通过吸收获得的额外容量；旧存档加载后也会自动获得上述基础值。

## 它能做什么

- **开箱即用** — 接入 ME 网络后即可存入、取出物品（在「自动接收后续物品」开启时主动接货）。
- **吸收 Cell 扩容** — 放入空存储元件，在基础容量之上叠加字节数和物品种类上限。
- **参与 ME 存储** — 接入网络后，物品可以存入或从 DAV 中提取（需开启「自动接收后续物品」才会主动接货）。
- **导入现有库存** — 首次接入时，可把网络里已有的物品逐步迁入 DAV。
- **自动扩容** — 容量用到一定程度后，自动从网络提取或合成新的 Cell 并吸收，无需手动盯容量。

## 接入 ME 网络

把 DAV 放在线缆或带 ME 功能的方块旁边，确保：

- 网络有**频道**分配给 DAV（与驱动器相同）。
- 网络处于**供能**状态。

未接入网络时，界面会显示「未接入 ME 网络」，导入与自动扩容都不会工作。

## 界面说明

| 区域 | 作用 |
| :--- | :--- |
| **左侧开关** | 「导入现有库存」「自动接收后续物品」「自动扩容」三个开关。 |
| **右侧吸收槽** | 放入待吸收的 Storage Cell（一次一个）。 |
| **容量面板** | 显示已吸收 Cell 数量、字节用量、物品种类用量（总容量 = 内置容量 + 已吸收 Cell 容量）。 |
| **扩容 Cell 选择** | 自动扩容时使用的 Cell 类型；从 JEI/EMI 拖入，右键清空。 |
| **状态行** | 当前操作结果（等待 Cell、正在合成、扩容完成等）。 |
| **样板指示** | 显示所选扩容 Cell 在 ME 网络中是否有可用合成样板。 |

## 吸收 Storage Cell

1. 右键打开 DAV，把**空的** AE2 Storage Cell 放入右侧吸收槽。
2. 吸收成功后，Cell 物品会消失，DAV 的字节上限和种类上限增加。
3. 若开启了「自动接收后续物品」，之后放入吸收槽的 Cell 会在接入网络时自动吸收。

**吸收规则：**

| 条件 | 结果 |
| :--- | :--- |
| 必须是 AE2 Storage Cell | 非存储元件会被拒绝 |
| 必须为空 Cell | 里面已有物品的 Cell 不会被吸收 |
| 一次只能放 1 个 | 堆叠数量大于 1 时不会吸收 |
| 无限/创造类 Cell | 不会被吸收（避免异常容量） |

## 三个开关

### 导入现有库存

开启后，DAV 在接入 ME 网络时，会**周期性**从网络库存中迁入物品，直到 DAV 满或网络里没有可迁入的内容。

适合：刚把 DAV 接上已有大量物品的网络，希望逐步把货集中过来。

### 自动接收后续物品

开启后，DAV 会作为网络的**优先存储目标**之一，主动接收存入网络的物品（在容量允许范围内）。

关闭时，DAV 仍可手动通过终端存取其中已有物品，但不会主动「抢」新货。

### 自动扩容

开启后，当**字节占用**或**物品种类占用**达到阈值（默认 80%）时，DAV 会尝试扩容：

1. **快路径** — 若 ME 网络里已有空的、类型匹配的 Storage Cell，直接提取并吸收，不占用合成 CPU。
2. **合成路径** — 若网络里没有空 Cell，向 ME 自动合成系统提交任务；合成完成后 DAV **自行接收**成品 Cell 并吸收。

使用自动扩容前请确认：

- 已在「扩容 Cell 选择」中指定 Cell 类型（例如 64k 物品存储元件）。
- ME 网络中有该 Cell 的**合成样板**，且原料与 CPU 可用。
- 界面显示「✓ 样板可用」。

关闭自动扩容，或更换扩容 Cell 类型时，进行中的合成任务会被取消。

## 服务器配置

在 `config/appliedinsight-server.toml` 中可调整全局自动扩容行为：

| 配置项 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `davAutoExpandEnabled` | `true` | 为 `false` 时，所有 DAV 的自动扩容开关均被忽略 |
| `davAutoExpandBytesThreshold` | `0.80` | 字节占用达到 80% 时可触发扩容 |
| `davAutoExpandTypesThreshold` | `0.80` | 种类占用达到 80% 时可触发扩容 |
| `davAutoExpandCooldownTicks` | `200` | 两次自动扩容尝试之间的最小间隔 |

## 拆除与放置

用镐拆下新版数字资产库时，掉落的方块物品会**保留**：

- 已吸收容量与内部存储的物品
- 三个开关与扩容 Cell 配置
- 吸收槽中尚未吸收的 Cell

重新放置后状态自动恢复。进行中的自动合成会在拆除时取消。

## 推荐设置流程

1. 制作 DAV 并接入 ME 网络（自带 2048 字节 / 126 种物品，可立即使用）。
2. 开启「自动接收后续物品」，让新货优先进入 DAV。
3. （可选）开启「导入现有库存」，把网络散货迁入 DAV。
4. （可选）放入空 Cell 吸收，在基础容量之上进一步扩容。
5. 在扩容槽选好目标 Cell，确认样板可用后开启「自动扩容」。

之后 DAV 会在容量紧张时自行「长大」，无需反复手动造 Cell 插入。

## 与命令执行块配合

DAV 是模组推荐的**主存储池**。配合[命令执行块](sorter-command-block.md)使用时：

- **碎片物品合并** — 减少网络中同类物品占用的槽位，为 DAV 腾出种类空间。
- **分析当前网络** — 在命令执行块中查看存储概览；DAV 的容量与碎片情况会单独标注，不参与传统 Drive 的单元格统计。
