# AI 提问模板

这个文件提供适用于本 NeoForge 1.21.1 项目的中文提问模板，方便你直接复制给 AI。

配合阅读：
- `docs/AI_DEVELOPMENT_GUIDE.md`

如果你希望，我后面也可以把 `AI_DEVELOPMENT_GUIDE.md` 一并改成中文版。

## 核心规则

除非我明确说明，否则请默认：

- 只使用本项目对应的 NeoForge `1.21.1` API
- 优先遵循当前项目已有结构和写法
- 不要猜 API
- 如果类、方法、构造器不确定，先用 `tools/javap_lookup.sh` 验证
- 只关注可调用 API，不展开源码实现细节
- 尽量做最小修改，方便审查

## 1. 先查 API 再编码

适用于：你不确定某个类怎么调用，想先让 AI 查清楚。

```text
先用项目里的 tools 工作流检查这个类：
<完整类名>

要求：
- 只根据已验证的 public API 签名回答
- 不要猜方法名或构造器
- 再告诉我这个类在当前项目里应该怎么用
```

示例：

```text
先用项目里的 tools 工作流检查这个类：
net.minecraft.world.level.block.entity.BlockEntityType

要求：
- 只根据已验证的 public API 签名回答
- 不要猜方法名或构造器
- 再告诉我这个类在当前项目里应该怎么用
```

## 推荐提问习惯

一个比较稳的提问方式是：

1. 先说任务
2. 如果知道关键类名，就直接说出来
3. 如果不确定钩子/API，就要求先验证
4. 最后要求“最小补丁”

示例：

```text
帮我添加一个自定义方块，并支持右键交互。
请先用 tools 工作流验证 1.21.1 下正确的交互钩子。
然后按当前项目风格做最小补丁。
```
