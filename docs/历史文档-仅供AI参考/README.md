# 历史文档（仅供 AI 参考）

这个目录中的文档属于：

- 历史方案
- 过渡期计划
- 已被新的主文档替代的说明
- 脑暴 / 草案 / 阶段性收敛记录

## 使用规则

1. **不要把这里的文档当作当前主文档。**
2. 当前有效文档以 `docs/` 根目录下的主文档为准，包括但不限于：
   - `ARCHITECTURE_REFERENCE.md` — 架构参考手册（全景）
   - `GLOSSARY.md` — 术语表
   - `整体逻辑.md` — 项目主骨架
   - `类职责总览.md` — 审查结论
   - `AI_DEVELOPMENT_GUIDE.md` — AI 协作规则
   - `ai/AI_ENTRY.md` — AI 协作者入口
   - `DEVELOPER_GUIDE.md` — 开发者指南
   - `前端对接说明.md` — 前端边界
   - `下一步计划.md` — 当前阶段方向
3. 如果历史文档与主文档冲突，**一律以主文档为准**。
4. 这里的内容只用于：
   - 回溯设计演变
   - 解释为什么过去做过某个判断
   - 给 AI 提供上下文参考
