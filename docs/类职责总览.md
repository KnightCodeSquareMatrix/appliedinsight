## 2. 本次审查结论（2026-06-08 · 0.9.0-beta）

已逐个查看 `src/main/java` 下的 **145 个 Java 类型**，结论如下：

### 2.1 整体边界是健康的

当前项目已基本形成以下边界：入口/装配层 → 命令/应用服务层 → AE2 集成层 → 纯规则层 → 离线分析层 → 规划模型层 → 玩家输入与界面层 → 日志基础设施层。

> **规则层没有被 Minecraft / AE2 运行时依赖污染。**

### 2.2 三条能力线 + 两条设备线

| 能力/设备 | 玩家入口 | 状态 |
|-----------|----------|------|
| Merge | `/sorter merge`、SCB GUI | 稳定 |
| Plan/PlanAndMove | `/sorter me planAndMove`、SCB GUI | 稳定（需 profile 绑定） |
| Storage 分析 | `/sorter me storageDump`、SCB GUI | 稳定（ADR-012 迁移中） |
| 数字资产库 DAV | 方块 `digital_asset_vault` | beta 主产品 |
| 智能总线 Smart Bus | AE2 Part `smart_bus` | beta 主产品（过滤器 + 12 stack/tick） |

### 2.3 当前主要技术债

1. **ADR-012 迁移进行中** — `RuntimeCell` 已删除；`StorageDiagnosis` 替代 raw `StorageAnalyzerReport`；部分 presenter 逻辑仍待完全回归服务端。
2. **类职责文档** — 核心 DAV / Smart Bus / 分析 presenter 路径已补齐（2026-06-08）；`FilterEditorSupport`、`ExpansionCellPickerWidget` 等辅助类仍可补充。
3. **`Ae2MoveAnalyzer`** — 孤立代码，未被能力路径调用。
4. **命名历史包袱** — Mod ID `appliedinsight`，Java 包 `appliedstoragesorter`，内部类前缀 `NewDav*`；文档已区分「对外名称 / Mod ID / 源码命名」。
5. **未注册资产** — `dark_matter_controller`、旧管理卡相关资源仍可能在仓库中；beta 对玩家不可见，清理推迟。

### 2.4 已移除 / 不再文档化为主路径

- 旧版 `digital_asset_vault`（legacy BE/GUI）
- `new_digital_asset_vault` 方块 ID（已合并为 `digital_asset_vault`）
- `DigitalAssetManagementCard` 物品与槽位
- 双 DAV 并存架构（见 [`RAW_ARCHITECTURE_AUDIT.md`](架构/RAW_ARCHITECTURE_AUDIT.md) 历史快照）
