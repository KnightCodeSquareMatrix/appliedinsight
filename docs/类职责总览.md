## 2. 本次审查结论

已逐个查看 `src/main/java` 下的 **129 个 Java 类型**，结论如下：

### 2.1 整体边界是健康的

当前项目已基本形成以下边界：入口/装配层 → 命令/应用服务层 → AE2 集成层 → 纯规则层 → 离线分析层 → 规划模型层 → 玩家输入与界面层 → 日志基础设施层。

> **规则层没有被 Minecraft / AE2 运行时依赖污染。**

### 2.2 第三条长期主线

除主路径 (Plan/PlanAndMove) 和简化 Merge 路径外，已形成第三条主线：宏观观测路径 (Storage Dashboard) — `/sorter me storageDump` → storage analyzer snapshot → storage dashboard → 节点语义层 → world save override（后续）。定位是提供 AE2 网络的宏观观测、解释、智能默认与用户纠偏能力。

### 2.3 当前主要技术债

1. **`DriveMachineAccessor`** — 已从纯反射策略升级为 `IChestOrDrive` 接口优先 + 反射 fallback 策略。反射保留用于不支持 `IChestOrDrive` 的第三方 drive。升级上游时仍需回归反射 fallback 路径
2. **`MergeMovePlanner`** — `/sorter merge` 的合并路径，与 zone 规划/执行链路并存，定位为"快速 merge 模式"
3. **`SorterMergeService`** — 负责 `/sorter merge`，面向低复杂度使用场景的保留入口
